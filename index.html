TEMA 01

Estructura y sintaxis de CSS

CSS significa hojas de estilo en cascada. Es un lenguaje que se utiliza para darle apariencia a una página web. Con él podemos cambiar colores, tamaños, tipos de letra, espacios, bordes y muchas otras cosas.

Una regla de CSS está formada por un selector y un bloque de declaraciones. El selector indica qué elemento queremos modificar y las declaraciones indican qué cambios queremos hacer.

Para recordar: HTML organiza el contenido de la página y CSS se encarga de su presentación visual.
h1 { color: purple; font-size: 30px; text-align: center; }

¿Qué significa cada parte?

  • h1: es el selector.
  • color: es una propiedad.
  • purple: es el valor.
  • font-size: cambia el tamaño del texto.
  • text-align: alinea el texto.
TEMA 02

CSS interno, externo y en línea

Existen tres formas principales de agregar CSS a un documento HTML. Todas sirven para cambiar el diseño, pero se utilizan de manera diferente.

Se escribe dentro de la etiqueta style, que normalmente se coloca en el head del documento HTML.
<head> <style> body { background-color: lavender; } </style> </head>
Es útil cuando queremos aplicar estilos a una sola página.

Se escribe en un archivo independiente con extensión .css y se conecta al HTML utilizando la etiqueta link.
<link rel="stylesheet" href="estilos.css">
En el archivo estilos.css podemos escribir:
body { background-color: lavender; } h1 { color: purple; }
Es una buena opción cuando tenemos varias páginas porque podemos compartir los mismos estilos.

Se agrega directamente en una etiqueta HTML utilizando el atributo style.
<p style="color: purple;"> Este es un texto de ejemplo. </p>
Es rápido para hacer un cambio puntual, pero no es recomendable utilizarlo para diseñar toda una página.
Mi recomendación: para proyectos más organizados, es mejor utilizar CSS externo porque permite separar el diseño del contenido HTML.
TEMA 03

Indentación, herencia y comentarios

Indentación

Es el espacio que dejamos al comienzo de algunas líneas de código para que sea más fácil leerlas y entender cómo están organizadas.

.card { padding: 20px; color: purple; }

Herencia

Es cuando algunos elementos reciben ciertos estilos de su elemento padre. Por ejemplo, el color del texto puede heredarse.

body { color: purple; font-family: Arial; }

Comentarios

Son notas que se escriben en el código para explicar algo. El navegador no las muestra en la página.

/* Este es un comentario */ h1 { color: purple; }
No todas las propiedades se heredan. Algunas, como el color, suelen heredarse, mientras que otras, como el margen, normalmente no lo hacen.
TEMA 04

Especificidad

La especificidad es una forma de determinar qué regla CSS tiene prioridad cuando varias reglas intentan modificar el mismo elemento.

Por ejemplo, si un párrafo tiene un estilo general, pero también tiene una clase, el estilo de la clase normalmente tendrá mayor especificidad.

En general, un selector de ID tiene más especificidad que una clase, y una clase tiene más que un selector de etiqueta. También influyen la cascada y el uso de !important.
p { color: blue; } .texto { color: purple; } #principal { color: red; }

Si el mismo elemento tiene estos selectores y las reglas compiten en las mismas condiciones, el ID tendrá prioridad.

TEMA 05

Flexbox, Grid y breakpoints

Son herramientas que ayudan a organizar los elementos de una página. Se utilizan para crear diseños ordenados y adaptables a diferentes tamaños de pantalla.

Flexbox

Flexbox permite organizar elementos en una fila o columna. Es útil cuando necesitamos alinear elementos y distribuir el espacio entre ellos.

.contenedor { display: flex; justify-content: center; align-items: center; gap: 10px; }

Grid

CSS Grid permite organizar elementos en filas y columnas. Es muy útil para crear distribuciones más completas, como galerías o secciones de una página.

.contenedor { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; }

Breakpoints

Son puntos de referencia que se utilizan para cambiar el diseño dependiendo del ancho de la pantalla. Por ejemplo, podemos mostrar tres columnas en un computador y una sola columna en un celular.

@media (max-width: 768px) { .contenedor { grid-template-columns: 1fr; } }
TEMA 06

Media Queries

Las Media Queries permiten aplicar diferentes estilos dependiendo de las características del dispositivo, principalmente el ancho de la pantalla.

Se utilizan mucho para hacer que una página web sea responsive, es decir, que se adapte a celulares, tabletas y computadores.

Una página responsive se ajusta al tamaño de la pantalla para que el contenido pueda verse y utilizarse correctamente.
.contenedor { width: 80%; margin: auto; } @media (max-width: 768px) { .contenedor { width: 95%; } } @media (max-width: 480px) { h1 { font-size: 25px; } }

¿Qué debemos tener en cuenta?

  • Que los textos se puedan leer sin hacer zoom.
  • Que las imágenes no se salgan de la pantalla.
  • Que los menús sean fáciles de utilizar.
  • Que los elementos se acomoden según el dispositivo.
TEMA 07

Pseudoelementos y pseudoclases

Pseudoclases

Las pseudoclases permiten aplicar estilos cuando un elemento se encuentra en un estado específico. Por ejemplo, cuando pasamos el mouse sobre un botón.

button:hover { background-color: purple; color: white; } input:focus { border: 2px solid purple; }

Pseudoelementos

Los pseudoelementos permiten modificar una parte específica de un elemento o agregar contenido decorativo sin tener que crear otra etiqueta HTML.

p::first-letter { color: purple; font-size: 30px; } h2::after { content: " ✦"; color: purple; }

TEMA 08

Z-index

La propiedad z-index sirve para controlar qué elemento aparece delante o detrás de otro cuando se superponen.

Para que funcione de la forma habitual, los elementos deben tener una posición diferente de static, como relative, absolute o fixed.

.caja1 { position: absolute; z-index: 1; } .caja2 { position: absolute; z-index: 2; }
Un número más alto normalmente indica que el elemento aparecerá delante. Sin embargo, también debemos tener en cuenta los contextos de apilamiento.

Lo que aprendimos

CSS es una parte importante del desarrollo web porque permite que una página no solamente tenga información, sino que también tenga una presentación organizada y agradable.

Conocer sus propiedades y herramientas nos ayuda a crear páginas que se adapten a diferentes dispositivos, organizar mejor los elementos y mejorar la forma en que las personas utilizan un sitio web.
